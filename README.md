# 🧠 AI Morning News Agent

一个基于 DeepSeek + Telegram + Railway 构建的 AI 晨报 Agent。

该项目能够每天自动获取：

* 全球金融市场
* 大盘涨跌
* AI 新闻
* 科技新闻
* 国际动态

并通过 DeepSeek AI 自动生成中文晨报，最后推送到 Telegram。

整个系统支持：

* 云端自动运行
* 定时任务
* 金融数据分析
* AI 新闻总结
* Telegram 消息推送

适合作为：

* AI Agent 学习项目
* 自动化工作流项目
* 金融信息聚合系统
* Telegram Bot 项目
* AI 晨报系统

的开源实践案例。
