# 🧠 AI Morning News Agent

一个基于 DeepSeek、Telegram 与 Railway 构建的智能 AI 晨报系统。

项目能够每天自动抓取全球科技与金融信息，包括：

* 🌍 全球主要市场指数
* 📈 大盘与板块涨跌
* 🤖 AI 行业动态
* 💻 科技新闻热点
* 📰 国际市场资讯

系统会使用 DeepSeek AI 自动分析新闻内容，提炼重点，并生成结构化中文晨报，最终通过 Telegram 自动推送到手机。

整个流程完全自动化：

```text
新闻抓取
    ↓
金融数据分析
    ↓
DeepSeek AI 总结
    ↓
Telegram 自动推送
```

项目特点：

* ✅ AI 自动晨报生成
* ✅ 全球金融市场分析
* ✅ Telegram Bot 推送
* ✅ Railway 云端部署
* ✅ 定时自动运行
* ✅ 支持 Markdown 晨报格式
* ✅ 可扩展多 Agent 架构
